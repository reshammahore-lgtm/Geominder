# Geominder (Prototype)

A browser-based prototype for creating and managing location-based reminders.

## Features
- Create reminders associated with a place
- Request the user's current location using browser Geolocation
- Store reminders locally using localStorage
- Delete reminders
- Responsive, simple interface

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Geolocation API
- localStorage

## How to Run
Open `index.html` in a modern browser. For geolocation, the browser may ask for location permission.

## Project Purpose
Geominder demonstrates the core concept of contextual reminders triggered by a user's location. This repository is a prototype rather than a production geofencing application.
